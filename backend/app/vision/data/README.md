# Facial Recognition Watchlist Data

This directory stores the facial recognition watchlist database.

## Files

- **watchlist.json** - Face embeddings database (auto-generated by train_watchlist.py)
- **watchlist.json.tmp** - Temporary file used during atomic saves

## Usage

The watchlist is populated by running the training script:

```powershell
cd backend
python -m app.vision.train_watchlist --name "Person Name" --folder "D:\path\to\photos"
```

## Format

The watchlist.json file contains:
- Person IDs and names
- 512-dimensional ArcFace embeddings per person
- Creation timestamps
- Embedding counts

Example:
```json
{
  "version": 1,
  "people": [
    {
      "person_id": 1,
      "name": "John Doe",
      "created_at": "2026-09-05 10:30:00",
      "embedding_count": 25,
      "embeddings": [[0.001, -0.002, ...], ...]
    }
  ]
}
```

## Notes

- Embeddings are L2-normalized for cosine similarity matching
- Multiple embeddings per person improve recognition accuracy
- Threshold for matching is 0.45 (configurable in face_recognizer.py)
